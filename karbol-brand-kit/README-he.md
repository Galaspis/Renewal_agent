# חבילת העיצוב של כָּרבוֹל

להתחלה: previews/brand-board.png ו-previews/icon-catalog.png.

- logos — לוגו אופקי, לבן, אנכי, כיתוב ותרנגול בנפרד; SVG ו-PNG שקוף160–1920.
- app — אייקון רגיל ו-maskable, כולל180/192/512/1024.
- favicon — ראש מפושט, SVG/ICO/PNG16–128.
- icons — 30 סמלים מקוריים, SVG צבעוני ו-mono, PNG24–256 ו-sprite.
- social — פייסבוק: פרופיל, קאבר1702×630 ו851×315, פוסט1200×630; אינסטגרם: פרופיל1080, פוסט1080, סטורי1080×1920. קובציSVG עריכים לצדPNG. יש לבדוק חיתוך בתצוגת הרשת החברתית.
- fonts — Heebo ורישיון.
- developer — צבעים, דוגמתhead, manifest. יש להתאים נתיבים לאתר.
- guidelines — כללי עיצוב, שימוש, RTL והניקוד המאושר.
- previews — הדמיה מקורית מאושרת, לוח מותג, קטלוג אייקונים ותקריב לוגו.

השם: כָּרבוֹל — קמץ ודגש בכ׳, חולם בו׳. הלוגו הווקטורי הוא מקור הייצור המחייב.

עדכון: נוספה עין לתרנגול בכל נכסי הייצור. תמונת ההדמיה ומקור ה-AI נשמרו כרפרנס היסטורי.
